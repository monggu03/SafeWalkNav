# SafeWalk 브랜드 자산

## 파일

| 파일 | 용도 |
| --- | --- |
| `safewalk_icon.svg` | 심볼 원본(512). 모든 래스터의 출처 |
| `safewalk_icon_foreground.svg` | Android 적응형 아이콘 전경 레이어 (안전 영역 62%로 축소, 배경 없음) |
| `safewalk_logo_horizontal.svg` | 가로형 로고 — **어두운 배경용**. 배경 투명, 밝은 글자 |
| `safewalk_logo_horizontal_light.svg` | 가로형 로고 — **밝은 배경·인쇄용**. 태그라인 영문 (SF 부스 포스터용) |
| `safewalk_icon_512.png` / `_1024.png` | 스토어 등록·발표자료용 |
| `safewalk_logo_horizontal*.png` | 위 SVG 의 1280×360 래스터 |

원본은 SVG입니다. 크기를 바꿀 일이 있으면 PNG를 늘리지 말고 SVG에서 다시 뽑으세요.

## 색

| 역할 | 값 | 비고 |
| --- | --- | --- |
| 보행 신호 인물 | `#00CC66` | 앱의 초록불 색과 동일 |
| 횡단보도 줄무늬 | `#FFD700` | 앱의 강조 노랑과 동일 |
| 심볼 배경 | `#0E1116` ~ `#1C1F26` | 적응형 아이콘 배경은 단색 `#0E1116` |

앱 UI(`activity_main.xml`)에서 쓰는 색을 그대로 가져왔습니다. 로고와 화면이 따로 놀지 않게 하려는 의도이니, 한쪽을 바꾸면 다른 쪽도 같이 확인하세요.

## 디자인 의도

보행 신호 인물이 횡단보도 위를 걷는 모습입니다. 앱이 하는 일(횡단보도에서 보행 신호를 읽어 주는 것)이 설명 없이 전달되는 것을 목표로 했습니다. 줄무늬는 아래쪽이 가장 넓고 밝아서 보는 사람 쪽으로 다가오는 원근을 만듭니다.

48px 런처 크기에서도 인물과 줄무늬가 구분되도록 팔다리를 굵게 잡았습니다. 형태를 수정할 때는 반드시 48px로 축소해서 확인하세요 — 큰 화면에서 예뻐 보이는 디테일이 런처에서는 뭉개집니다.

## 폰트

워드마크는 `Pretendard` → `Noto Sans KR` → 맑은 고딕 순으로 폴백합니다. 어느 것도 없으면 시스템 산세리프로 떨어지므로 자간이 달라질 수 있습니다. 최종 인쇄물을 만들 때는 글자를 아웃라인(패스)으로 변환해 두는 편이 안전합니다.

## Android 런처 아이콘

`androidApp/src/main/res/` 아래에 이미 반영돼 있습니다.

- `mipmap-{mdpi~xxxhdpi}/ic_launcher.png`, `ic_launcher_round.png` — 레거시 48dp
- `mipmap-{...}/ic_launcher_foreground.png` — 적응형 전경 108dp
- `drawable/ic_launcher_background.xml` — 적응형 배경(단색). 안드로이드 스튜디오 기본 초록 격자를 교체한 것

기존 `.webp` 파일은 같은 이름의 `.png` 와 리소스 이름이 충돌하므로 전부 삭제했습니다. 아이콘을 다시 뽑을 때도 한 형식만 남기세요.

적응형 아이콘의 `<monochrome>` 은 전경 레이어를 재사용합니다. 안드로이드 13+ 테마 아이콘에서는 색이 전부 벗겨지고 실루엣만 남으므로, 인물과 줄무늬가 겹치지 않게 배치한 현재 구성이 필요합니다.
