# SafeWalk 보행 자기효능감 설문지

**대상**: 관악구 실로암시각장애인복지관 협력 베타테스터 10명
**시점**: 사용 전(사전) / 사용 12주 후(사후) — **동일 문항으로 2회 실시**
**소요**: 약 20분 (구술 진행 기준)

---

## ⚠️ 척도 선정 근거 (보고서·발표용)

기존 계획서에 기재했던 **PSEQ(Pain Self-Efficacy Questionnaire)는 만성통증 환자용 척도**로, 요통·섬유근육통 환자가 *통증에도 불구하고* 활동할 수 있다는 자신감을 측정하는 도구입니다. 시각장애인의 보행 자기효능감 측정에는 적합하지 않아 다음과 같이 재설계하였습니다.

| 구성 | 도구 | 성격 |
|---|---|---|
| Part A | **GSE (General Self-Efficacy Scale)**, Schwarzer & Jerusalem | 국제적으로 검증된 표준 척도. 시각장애인 대상 연구(PLOS One, 2021)에서 사용 실적 있음 |
| Part B | **횡단보도 보행 자기효능감** (자체 개발) | Bandura의 자기효능감 척도 작성 지침에 따라 개발. 본 프로젝트의 핵심 변화 측정 |
| Part C | **행동 지표** (자기보고) | 실제 행동 변화. Before/After 동선 비교의 근거 |
| Part D | **정성 인터뷰** (사후만) | 수치로 안 잡히는 변화 + 지불 의사 확인 |

> 검증된 범용 척도(A)와 도메인 특화 문항(B)을 병행하는 것은, 표준 비교가능성과 프로젝트 특수성을 동시에 확보하기 위한 설계입니다.

---

## 📋 실시 방법 (중요 — 접근성)

- **종이 설문지는 사용하지 않습니다.** 조사자가 문항을 읽어주고 응답을 기록하는 **대면 또는 전화 구술 방식**으로 진행합니다.
- 온라인 폼을 쓸 경우, **스크린리더(VoiceOver/TalkBack) 호환성을 반드시 사전 테스트**합니다.
- 사전·사후 조사자를 동일인으로 유지합니다.
- 응답에 정답이 없음을 먼저 안내하고, 편하게 답하도록 합니다.

# Part A. 일반 자기효능감 (GSE)

> **안내문**: 다음 문장이 자신에게 얼마나 해당하는지 말씀해 주세요.
> **1점** 전혀 아니다 / **2점** 거의 그렇지 않다 / **3점** 대체로 그렇다 / **4점** 매우 그렇다

| # | 문항 | 점수 |
|---|---|---|
| A1 | 충분히 노력하면 어려운 문제도 항상 해결할 수 있다. | ☐1 ☐2 ☐3 ☐4 |
| A2 | 누군가 나를 반대해도, 내가 원하는 것을 얻을 방법을 찾을 수 있다. | ☐1 ☐2 ☐3 ☐4 |
| A3 | 목표를 정하고 끝까지 해내는 것이 나에게는 어렵지 않다. | ☐1 ☐2 ☐3 ☐4 |
| A4 | 예상치 못한 일이 생겨도 잘 대처할 자신이 있다. | ☐1 ☐2 ☐3 ☐4 |
| A5 | 나는 임기응변이 있어서 예상 밖의 상황도 다룰 줄 안다. | ☐1 ☐2 ☐3 ☐4 |
| A6 | 필요한 노력을 들이면 대부분의 문제를 해결할 수 있다. | ☐1 ☐2 ☐3 ☐4 |
| A7 | 나는 대처 능력이 있기 때문에 어려운 일이 닥쳐도 침착할 수 있다. | ☐1 ☐2 ☐3 ☐4 |
| A8 | 문제에 부딪히면 대개 여러 가지 해결책을 찾아낼 수 있다. | ☐1 ☐2 ☐3 ☐4 |
| A9 | 곤란한 상황에서도 보통 해결 방법을 떠올릴 수 있다. | ☐1 ☐2 ☐3 ☐4 |
| A10 | 나에게 어떤 일이 닥치든 대체로 잘 해낼 수 있다. | ☐1 ☐2 ☐3 ☐4 |

**채점**: 단순 합산. **범위 10~40점**. 점수가 높을수록 자기효능감이 높음.

# Part B. 횡단보도 보행 자기효능감 ★ 핵심 지표

> **안내문**: 지금 이 순간을 기준으로, 다음 일을 **혼자서** 해낼 수 있다는 자신감이 얼마나 되는지 **0점에서 10점 사이**로 말씀해 주세요.
> **0점** = 전혀 자신 없다 / **5점** = 반반이다 / **10점** = 완전히 자신 있다

| # | 문항 | 점수(0~10) |
|---|---|---|
| B1 | **음향신호기가 없는** 횡단보도를 혼자 건널 수 있다. | ____ |
| B2 | **음향신호기가 고장 난** 횡단보도에서 스스로 신호를 확인할 수 있다. | ____ |
| B3 | 지금 신호가 **빨간불인지 초록불인지** 스스로 판단할 수 있다. | ____ |
| B4 | **주변에 사람이 없는 시간대**(새벽·심야)에 혼자 횡단보도를 건널 수 있다. | ____ |
| B5 | **처음 가보는** 횡단보도를 혼자 건널 수 있다. | ____ |
| B6 | 횡단보도를 건널 때 **내가 직접 판단해서** 건널 수 있다. | ____ |
| B7 | 횡단보도가 포함된 **새로운 경로**로 혼자 외출할 수 있다. | ____ |
| B8 | 가고 싶은 곳이 있으면 **혼자서 갈 수 있다**. | ____ |

**채점**: 단순 합산. **범위 0~80점**. 문항별 점수도 개별 분석(어느 상황의 자신감이 올랐는지).

> **분석 포인트**: B1~B3(신호 인지)은 앱의 직접 효과, B4~B8(외출 확장)은 파급 효과. 앱이 신호 인지만 올리고 외출 확장으로 이어지지 않는다면, **가치 전환에 실패한 것**이므로 8월 피벗 근거가 됩니다.

# Part D. 정성 인터뷰 (사후 조사에서만 실시)

## D-1. 핵심 질문 ★ (강의의 "좌절할 고객" 테스트)

> **D1. 만약 내일부터 SafeWalk를 더 이상 쓸 수 없게 된다면, 어떨 것 같으세요?**
> (자유 응답 → 아래 중 어디에 해당하는지 조사자가 분류)
>
> ☐ 매우 곤란하다 / 예전으로 못 돌아간다
> ☐ 아쉽지만 지낼 만하다
> ☐ 별 차이 없다
>
> **판정 기준**: "매우 곤란하다"가 **10명 중 5명 이상**이면 가치 검증(1단계) 통과.

## D-2. 사용 경험

- **D2.** SafeWalk가 가장 도움이 되었던 순간은 언제였습니까? 구체적인 상황을 말씀해 주세요.
- **D3.** 반대로, 불편했거나 **믿기 어려웠던** 순간이 있었습니까?
- **D4.** SafeWalk를 쓰면서 **예전에는 하지 않던 행동**을 하게 된 것이 있습니까? (예: 혼자 나가본 곳, 새로 다녀본 길)
- **D5.** 앱이 알려준 신호가 **틀렸다고 느낀 적**이 있습니까? 있다면 어떤 상황이었습니까? *(안전 필수 확인 문항)*

## D-3. 지속가능성 / 지불 의사

- **D6.** 주변의 다른 시각장애인에게 이 앱을 추천하시겠습니까? (☐예 ☐아니오) 이유는요?
- **D7.** 만약 이 앱이 유료라면, **한 달에 얼마까지** 낼 의향이 있으십니까? (☐무료만 / ☐1천원 / ☐3천원 / ☐5천원 / ☐1만원 이상)
- **D8.** 만약 복지관이나 구청이 대신 비용을 부담한다면, 계속 쓰시겠습니까?

> **D7·D8의 의미**: 강의의 MVP 1원칙("유료 고객 확보 계획")에 대응합니다. 사용자가 직접 지불하지 않더라도, **누가 지불할 것인가**(복지관·지자체)를 검증하는 근거가 됩니다.

# 📊 분석 계획

## 1. 주 지표 (사전 vs 12주 후)

| 지표 | 산출 | 목표 |
|---|---|---|
| **횡단보도 자기효능감** (Part B 총점) | 사후 − 사전 | **+20% 이상** |
| 일반 자기효능감 (Part A 총점) | 사후 − 사전 | 상승 확인 |
| **못 가던 목적지 회복률** (Part C-3) | 혼자 다녀온 목적지 수 ÷ 사전 목록 수 | **1인당 최소 1곳** |
| 주간 혼자 외출 횟수 (C1) | 사후 − 사전 | 증가 확인 |
| 회피·포기 경험 (C4·C5) | 사후 − 사전 | 감소 확인 |

## 2. 가치 검증 판정 (8월 피벗 결정용)

- **D1에서 "매우 곤란하다" 5명 이상** → 시나리오 (A): 정확도·UX 개선 + 확대
- **5명 미만** → 시나리오 (B): **타겟 또는 제품 변경**

## 3. 안전 지표 (별도, 필수)

- **D5에서 "빨간불을 초록불로 알려줬다"는 응답 = 0건**이어야 함. 1건이라도 나오면 **즉시 원인 분석 및 배포 중단 검토.**

## 4. 표본 한계 (보고서에 명시할 것)

n=10의 소표본이므로 **통계적 유의성 검정보다 개별 사례의 변화 추적(사례 연구)** 중심으로 해석합니다. 대조군이 없으므로 인과 추론에는 한계가 있으며, 이는 보고서에 명시합니다.

## 부록: 사전 조사 진행 순서

1. 연구 목적 설명 및 **동의 취득** (녹음 여부 별도 동의)
2. Part A (GSE) — 약 4분
3. Part B (횡단보도 자기효능감) — 약 5분
4. Part C (행동 지표 + **못 가는 목적지 목록**) — 약 8분
5. 앱 설치 및 사용법 안내
6. 12주 후 사후 조사 일정 안내

**사후 조사 시**: Part A → B → C → **D(정성 인터뷰)** 순으로 진행하며, C-3은 **사전에 작성한 목록을 읽어드리며** 확인합니다.
