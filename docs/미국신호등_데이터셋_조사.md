# 미국 보행 신호등 데이터셋 조사 (2026-07)

> 목적: 한국+미국 통합 신호등 검출 모델 학습용 데이터 확보.
> 조건: **YOLO 검출 형식(바운딩박스)** + **red/green 2클래스로 정리 가능** + 라이선스 허용.

---

## 결론 먼저

**"확인된 미국 데이터"와 "검출 형식"이 동시에 만족되는 대형 공개 데이터셋은 드물다.** 현실적 경로는 둘 중 하나:

- **경로 A (권장): Roboflow 병합.** 한국 2클래스 검출 데이터 + 미국 보행신호 검출 데이터를 Roboflow에서 red/green 으로 통일해 한 번에 export. Roboflow 가 형식·병합·증강·분할을 다 처리한다.
- **경로 B: 로컬 병합.** kairess(단, 이미지가 저장소에 없음 → WeSee 별도 확보 필요) + 미국 YOLO 데이터셋을 로컬에서 클래스 리매핑해 병합. 손이 많이 간다.

아래 스크립트(`ml_experiments/train_unified_kr_us.py`)는 **경로 A**를 기본으로 한다.

---

## 후보 데이터셋 상세

### 1. ImVisible / PTL — 미국식, 대형, 그러나 검출 형식 아님 ❌
- 출처: [samuelyu2002/ImVisible](https://github.com/samuelyu2002/ImVisible) (LYTNet, CAIP'19 / ICCV Workshops'19)
- 규모: **5,059장** (train 3456 / val 864 / test 739)
- 클래스: Red 1477 / Green 1303 / Countdown Green 963 / Countdown Blank 904 / None 412
- 라이선스: **MIT** (가장 관대)
- 성격: 미국식 보행신호(주황손=Red, 흰사람=Green, 카운트다운) — **우리 미국 타겟과 정확히 일치**
- **치명적 한계:** 이미지 **분류(classification)** 데이터다. 라벨의 좌표(x1,y1,x2,y2)는 **신호등이 아니라 횡단보도 중심선**이다. 신호등 바운딩박스가 없어 YOLO 검출 학습에 그대로 못 쓴다.
- 활용 가능성: (a) 검출용으로 쓰려면 신호등 bbox 를 새로 라벨링해야 함(수작업), (b) 분류 보조/검증 세트로만 활용, (c) LytNet 계열(분류+좌표회귀) 아키텍처면 바로 쓰지만 우리 YOLO 파이프라인과 다름.
- **판단: 이번 검출 통합에는 부적합. 향후 미국 실측 라벨링의 참고·검증용으로만.**

### 2. Roboflow `ono/pedestrian-traffic-light` — 검출 형식, 소형, 미국 여부 불확실 🟡
- 출처: [Roboflow Universe](https://universe.roboflow.com/ono-gedd7/pedestrian-traffic-light-puf4a)
- 규모: 926장 (증강 버전 2,222장)
- 클래스: red, green, trafficlight, pedestrian Traffic Light, signal-light, traffic_light (**6개, 지저분함** — red/green 만 취하면 됨)
- 성능(자체): mAP50 92.0%
- 라이선스: **CC BY 4.0** (출처 표기 시 사용 가능)
- **주의:** 데이터 출처(국가)가 명시 안 됨. **미국 신호인지 이미지를 직접 눈으로 확인해야 한다** (browse 페이지에서 주황손/흰사람인지 vs 한국/기타인지). 확인 전 미국 데이터로 신뢰 금지.

### 3. Roboflow "pedestrian traffic light" 계열 다수 🟡
- [검색: pedestrian traffic light 검출](https://universe.roboflow.com/search?q=class:pedestrian+traffic+light)
- red/green 2클래스 검출 데이터가 여럿. 국가·품질 편차 큼. **미국 신호 포함 여부를 브라우저에서 육안 확인 후 선택.**

### 4. PTL-Crosswalk (ADAPT 프로젝트) — 문화적 다양성 표방 🟡
- 논문 검색에서 언급됨. 100개 교차로 스마트폰 촬영 + ADAPT 팀 영상. 공개 접근성·형식 미확인. 추가 조사 필요.

### 5. 참고 (한국측 · 이미 보유/접근 가능)
- **SafeWalk 자체 Roboflow 데이터** `pedestrian-traffic-light` (939장, **이미 red/green 2클래스 검출**) — 통합의 한국측 소스로 가장 깔끔.
- **kairess / SelectStar WeSee** (6,593장, 검출) — 단 **kairess 저장소엔 이미지 없음**. WeSee 원본을 [open.selectstar.ai](https://open.selectstar.ai) 에서 별도 확보해야 함. 클래스: Zebra_Cross/R_Signal/G_Signal → red/green 리매핑 필요.

## 권장 조합 (SF 데모 목표 기준)

| 목적 | 한국측 | 미국측 |
|---|---|---|
| **빠르게 통합 데모** | SafeWalk 자체 Roboflow 939장 (red/green) | Roboflow 미국 보행신호 검출셋 (육안 확인 후) |
| 대규모(시간 있으면) | WeSee 6,593장 (리매핑) | 위 + ImVisible 재라벨링 |

**핵심 안전 규칙:** 어떤 소스든 최종 클래스는 **red(0)=정지신호(주황손/빨간사람), green(1)=보행신호(흰사람/초록사람)** 로만 통일. 빨강↔초록이 뒤바뀌면 사람이 다친다. 병합 후 라벨을 반드시 육안 검증(스크립트에 검증 단계 포함).
